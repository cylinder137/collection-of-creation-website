# 造物集官网后端接口文档

> 版本：v0.1（开发阶段）
> 更新时间：2026-08-31
> 后端框架：Spring Boot 3.5 + MyBatis + MySQL 8.0
> 服务端口：`8080`（经 Nginx 反向代理对外提供服务）

---

## ⚠️ 服务器地址说明（前端必读）

**当前项目还没有确切的服务器 IP。**

- 前端代码中**禁止**写死任何服务器 IP/域名，统一使用环境变量字段 `VITE_API_BASE` 代替服务器地址：
  - 开发环境：`.env.development` 中 `VITE_API_BASE=/api`（由 Vite 代理转发到本机 `localhost:8080`）
  - 生产环境：`.env.production` 中 `VITE_API_BASE=/api`（由 Nginx 同源反向代理到后端）
- 后期服务器完成部署后，只需把 `VITE_API_BASE` 替换为实际地址（如 `https://api.zaowuji.com`）或配置 Nginx 域名，**前端业务代码零改动**。
- 前端 `src/api/http.ts` 中 `baseURL: import.meta.env.VITE_API_BASE || '/api'` 是唯一读取该字段的位置，请勿在其他地方硬编码地址。

## 通用约定

### 响应格式

所有接口统一返回 JSON：

```json
{
  "code": 0,          // 0 = 成功；非 0 = 业务错误
  "data": { ... },    // 业务数据（失败时为 null）
  "message": "ok"     // 错误时携带错误描述
}
```

### 错误码

| code | 含义 |
|------|------|
| 0    | 成功 |
| 400  | 参数校验失败 / 业务错误 |
| 404  | 资源不存在 |
| 500  | 服务器内部错误 |

### 金额单位

- 数据库存储单位为**分**（INT）
- 接口对外返回单位为**元**（JSON 数字，如 `199.00`）
- 前端展示直接使用接口返回值，无需换算

### 机器码约定

- 客户端提交**明文机器码**，服务端 SHA-256 哈希后存储/比对
- 同一产品 + 同一机器码重复申请激活码，接口幂等返回已有记录

### 2. 产品列表

`GET /api/products`

获取全部上架产品（按 sort 升序）。

> 💡 此接口结果在服务端缓存 5 分钟（Caffeine 本地缓存），重复请求直接返回缓存，不查询数据库。后台改价/上下架后最多 5 分钟生效。

**响应示例：**

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "name": "coBrain 白板笔记编辑器",
      "code": "coBrain",
      "description": "面向团队协作的白板笔记编辑器，支持多端同步与手写识别。",
      "version": "1.0.0",
      "coverUrl": null,
      "price": 199.00,
      "status": 1,
      "sort": 1
    }
  ],
  "message": "ok"
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 产品 ID |
| name | string | 产品名称 |
| code | string | 产品编码 |
| description | string | 产品简介 |
| version | string | 当前版本号 |
| coverUrl | string/null | 封面图 URL |
| price | number | 价格（元） |
| status | number | 1上架 0下架 |
| sort | number | 排序权重，越小越靠前 |

### 4. 创建订单

`POST /api/orders`

**请求体：**

```json
{
  "productId": 1,
  "contact": "user@example.com",
  "remark": "希望尽快发货"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| productId | number | 是 | 产品 ID |
| contact | string | 是 | 下单人联系方式（手机/邮箱），当前作为用户标识 |
| remark | string | 否 | 备注 |

**响应示例：**

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "orderNo": "202608311421408686595",
    "productId": 1,
    "productName": "coBrain 白板笔记编辑器",
    "amount": 199.00,
    "status": 0,
    "createdAt": "2026-08-31T14:21:40"
  },
  "message": "ok"
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 订单 ID |
| orderNo | string | 订单号（业务唯一，前端可用作展示） |
| productId | number | 产品 ID |
| productName | string | 产品名快照 |
| amount | number | 订单金额（元） |
| status | number | 0待支付 1已支付 2已取消 3已退款 4已签发 |
| createdAt | string | 创建时间 |

> ⚠️ 当前版本订单创建后状态为 `0待支付`；微信支付接入后由支付回调驱动状态流转，届时补充支付相关接口文档。

**错误：** 产品不存在 / 已下架时返回对应业务错误。

### 6. 申请激活码

`POST /api/activations`

提交机器码，服务端签发激活码（幂等：同一产品 + 同一机器码重复提交返回已有记录）。

**请求体：**

```json
{
  "productId": 1,
  "machineCode": "ABC-1234-DEFG"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| productId | number | 是 | 产品 ID |
| machineCode | string | 是 | 客户端硬件机器码（明文提交，服务端哈希存储） |

**响应示例：**

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "code": "5a9b5c9df200f60d1aef0ce9c373ea949e8fb0b9f9841087ec4c34975d16c129-1",
    "productId": 1,
    "productName": "coBrain 白板笔记编辑器",
    "machineCode": "ABC-1234-DEFG",
    "status": 0,
    "createdAt": "2026-08-31T14:21:46"
  },
  "message": "ok"
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 激活码记录 ID |
| code | string | 激活码内容（payload） |
| productId | number | 产品 ID |
| productName | string | 产品名 |
| machineCode | string | 绑定的机器码（明文回显） |
| status | number | 0未激活 1已激活 2已吊销 3已过期 |
| createdAt | string | 签发时间 |

> ⚠️ 安全说明：激活码 `sign`（RSA 签名）字段当前为占位值，接入 RSA 私钥签发后，客户端激活软件时须验签 + 比对机器码哈希 + 校验状态，**严禁只按"激活码存在"放行**。软件侧激活校验接口将在 RSA 接入后补充。

## 部署架构

```
客户端 (浏览器/App)
    │  大量短连接
    ▼
Nginx (80) ── 静态文件直出 ──► html/js/css/图片（不占用后端线程）
    │  keepalive 长连接池 (64)
    ▼
Spring Boot (127.0.0.1:8080)
    │  MyBatis
    ▼
MySQL (3306, 库 zaowuji)
```

**性能优化要点（Nginx 配置见 `deploy/nginx/zaowuji.conf`）：**

1. **静态文件直出**：js/css/图片由 Nginx 直接返回并长缓存 30 天，不经过 Java 后端
2. **长连接池**：客户端短连接由 Nginx 吸收，Nginx 与后端间用 `keepalive 64` 维持长连接，避免频繁建连/断连
3. **结果缓存**：
   - Nginx 层：`proxy_cache` 缓存 GET 成功响应 60 秒（产品列表/详情等只读接口）
   - 应用层：Caffeine 本地缓存产品数据 5 分钟
   - 双重缓存下重复请求基本不穿透到数据库

## 本地开发

```bash
# 1. 准备环境变量（数据库密码，禁止写进配置文件）
setx DB_PASSWORD 你的数据库密码

# 2. 启动后端（需 MySQL 已建库 zaowuji）
cd back_end
mvn spring-boot:run

# 3. 前端开发（Vite 代理 /api → localhost:8080）
cd front_end
npm run dev
```
